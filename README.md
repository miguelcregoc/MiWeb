# Primer repo de gitHub

## Anotaciones
Tuve problemas al subir sin querer un archivo que no sabia que habia commiteado.
Los pasos a seguir para ~~eliminarlos~~ fueron:

**ANTES DE NADA** hacer un [git status](https://git-scm.com/docs/git-status) y un [git log](https://git-scm.com/docs/git-log) para tener contexto de lo que hay en git
1. hacer un git clone del repo entero  (este paso solo lo hice porque use un ordenador diferente al que hizo el primer push)
2. eliminar la carpeta sobrante con ```git rm -r (carpeta eliminada)```
3. hacer el commit
4. pushear los cambios
